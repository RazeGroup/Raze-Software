# FLO Shopify Theme

A modern, premium Shopify theme for FLO - Smart NFC & Digital Identity Solutions.

## Theme Structure

```
├── assets/
│   ├── styles.css
│   └── script.js
├── config/
│   ├── settings_schema.json
│   └── settings_data.json
├── layout/
│   └── theme.liquid
├── locales/
│   └── en.default.json
├── sections/
│   ├── about.liquid
│   ├── footer.liquid
│   ├── header.liquid
│   ├── hero.liquid
│   ├── how-it-works.liquid
│   ├── lifestyle-banner.liquid
│   ├── main-collection-product-grid.liquid
│   ├── main-product.liquid
│   ├── products.liquid
├── templates/
│   ├── 404.liquid
│   ├── cart.liquid
│   ├── collection.liquid
│   ├── index.liquid
│   ├── page.liquid
│   ├── product.liquid
│   └── search.liquid
```

## Installation

1. Zip the entire theme folder
2. Upload to your Shopify store through the Themes section
3. Customize content through the Shopify Theme Editor

## Key Features

- Fully responsive design
- Modern dark theme with electric violet accents
- NFC product showcase
- Customizable sections
- SEO optimized
- Mobile-first approach

## Customization

You can customize the theme through Shopify's Theme Editor:
- Colors
- Fonts
- Content sections
- Images
