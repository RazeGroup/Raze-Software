## 📱 Responsive Design

The site is fully responsive across all screen sizes:

- **Desktop** — Full layout (≥ 993px)
- **Tablet** — Adapted grid, hamburger menu (≤ 992px)
- **Mobile** — Single-column, touch-optimized (≤ 640px)
- **Small Mobile** — Compact typography (≤ 380px)

## 🌐 Running Locally

No build step required — this is a static website.

```bash
# Clone the repository
git clone https://github.com/RazeGroup/raze-software.git

# Open in browser
open index.html
# or use a local dev server
npx serve .
```
